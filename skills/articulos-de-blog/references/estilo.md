# Estilo de redacción

Formula el propósito en una frase antes de redactar. “Al terminar, un supervisor podrá identificar qué rondines quedaron pendientes” permite elegir ejemplos, detalle y vocabulario. “Hablar sobre un sistema de rondines” deja abierta la pregunta que el artículo debe resolver.

| Si el lector necesita… | Enfoque | Cómo desarrollarlo |
| --- | --- | --- |
| Elegir qué hacer con un problema de su negocio | Divulgación práctica | Abre con la situación. Compara opciones mediante tareas, restricciones y consecuencias que el lector pueda reconocer. |
| Entender un concepto de IA, programación o una herramienta | Explicación | Define el término en lenguaje cotidiano. Muestra una acción y su resultado en un ejemplo. |
| Reproducir una implementación en Titanium, Laravel o una API | Tutorial técnico | Abre con el problema y el resultado esperado. Incluye requisitos, pasos y una comprobación cuando el lector vaya a seguirlos. |
| Considerar la postura de un autor | Opinión o ensayo | Plantea la pregunta, presenta la postura y distingue los hechos de la interpretación. Conserva la voz y los matices del autor. |

Decide cuánto detalle incluir según la tarea. Para un dueño de negocio, explica que una API permite que el pedido de la tienda llegue al sistema de inventario. Para quien tiene que conectar esos sistemas, describe qué datos se envían y cómo se comprueba que la operación se completó. Si el artículo sirve a ambos públicos, explica primero la consecuencia para el negocio y reserva la implementación para una sección con su propio subtítulo.

Para redactar el artículo completo, sigue [Redacción y revisión de artículos](redaccion-y-revision.md).
